# Исправления после повторного аудита — 7 сентября 2026

Ветка: `codex/crm-improvements-20260905`, draft PR #5. Это исправление подтверждённых дефектов, а не закрытие всей программы из 11 разделов.

## Реализовано

1. Дашборд получает денежные итоги, число неназначенных активных и завершённых оплаченных заказов из полной серверной выборки. Активная очередь запрашивается отдельно, без ограничения первыми 40 заказами. Доля оплат использует одну и ту же выборку и исключает оплаты отменённых заказов.
2. История клиента и автомобиля загружается страницами по 50. Суммы клиента вычисляются сервером по всем заказам; неизвестные суммы не превращаются в ноль.
3. История событий заказа получила кнопку загрузки следующих страниц.
4. Отменённые оплаты исключены из общего снимка печатного документа.
5. Сервер проверяет право сотрудника на запись и отмену оплаты. Контекст рабочего пространства передаёт эффективное право интерфейсу, который отключает соответствующие действия.
6. Деактивация принимает запрос с одним полем `is_active`; отключённое членство больше не допускает запросы.
7. Синхронные операции сессий используют собственный синхронный пул Redis без переноса асинхронных соединений между циклами событий.
8. В приёмке устранена панель кнопок, перекрывавшая нижние поля. Общие поля и списки могут сжиматься в сетке, подписи переносятся, кнопки действий переходят на следующую строку. На планшетах до 1024 px используется нижняя навигация, освобождая место форме. В карточке заказа блок назначения исполнителей переходит в несколько строк при недостатке места.
9. Исправлены лишние запятые в составных названиях Select и перевод роли владельца в боковом меню.
