## Возврат и проверка

Каждый этап сохраняется самостоятельным коммитом, веткой и описанием проверок. Для просмотра предыдущего состояния безопаснее открыть отдельную рабочую копию: `git worktree add ../autoser-before-improvements backup/pre-improvements-20260905`. Она не изменяет текущий код. Запускать её нужно с отдельной восстановленной локальной базой и свободными портами.

Для отмены конкретного изменения используется обратный коммит (`git revert`) в ветке улучшений с разрешением зависимостей между этапами, а не удаление истории. Откат кода не откатывает данные. Новые миграции должны сохранять прежние записи; восстановление всей базы выполняется только по отдельному запросу, поскольку оно заменяет изменения после резервной копии.

Слияние в `main` и production-развёртывание требуют отдельного финального подтверждения согласно AGENTS.md.
